# ClipFlow v3.0 更新说明

ClipFlow v3.0 重点提升了解析和下载过程的稳定性，同时保留了原有的抖音、小红书解析、下载、历史记录和设置功能。

## 这次更新了什么

### 解析和下载更稳定

- 抖音和小红书的解析流程更加独立，遇到某个平台的问题时更容易定位和恢复。
- 解析失败时会显示更明确的提示，方便检查链接和网络状态。
- 下载进度管理更加稳定，切换页面或返回解析页后仍能看到正确状态。
- 下载完成后，文件保存结果和系统通知更加可靠。

### 使用体验更一致

- 抖音和小红书页面使用一致的输入、加载、错误、结果和下载操作。
- 历史记录可以重新打开对应的解析页面。
- 解析历史、下载进度和关于页面的显示更加统一。

## 升级说明

- 不需要清除旧数据。
- 原有的解析历史、下载位置、应用设置和隐私同意状态会保留。
- 本版本最低支持 Android 12（API 31）。

## 安装方式

1. 下载本版本 Release 中的 `ClipFlow-v3.0.apk`。
2. 点击 APK 开始安装。
3. 如果 Android 提示允许当前来源安装应用，请按提示打开权限。
4. 安装完成后，可以关闭“允许安装未知应用”权限。
