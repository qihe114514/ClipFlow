# ClipFlow v3.0

v3.0 是一次以稳定性、可维护性和界面一致性为重点的内部重构版本。现有抖音/小红书解析、下载、历史、设置和关于页入口保持不变。

## 本次更新

### 更稳定的解析与下载
- 解析链路按平台适配器拆分，链接处理、接口解析和错误映射不再集中在单个大仓库中。
- 下载状态按任务管理，下载弹层、后台药丸和返回解析页后的状态恢复更一致。
- 历史记录通过路由参数恢复对应的解析页面，减少跨页面状态耦合。

### 更一致的使用体验
- 抖音和小红书解析页现在使用同一套输入、错误、加载、结果和下载进度展示逻辑。
- 保持原有页面布局和功能入口，同时拆分解析结果、导航栏、历史条目和关于页通用组件。
- 保存封面时的网络请求和协程生命周期已收口，离开页面后不会遗留临时工作。

## 升级说明

- 不需要清除数据。
- 历史记录、下载目录、设置和隐私同意状态会保留。
- APK 为 Android 12（API 31）及以上版本构建。

## 安装

下载并安装本 Release 中的 `ClipFlow-v3.0.apk`。Android 可能会提示授权当前安装来源安装未知应用，确认后即可完成安装。
