# ClipFlow v3.2 更新说明

## B 站解析

- 新增哔哩哔哩视频解析，支持 `bilibili.com/video/BV...`、`b23.tv` 短链和多分 P 视频。
- 使用用户主动登录后的本地加密 Cookie 会话，按账号权限获取可用清晰度。
- 支持视频、音频分别下载并合成为单个 MP4；过期直链、下载失败和封装失败会清理临时文件并显示明确提示。
- 解析结果包含标题、作者和封面，并写入历史记录，可从历史重新解析。

## 关于和开源

- 关于页在更新与隐私之间新增“开源与须知”独立页面。
- 页面说明 GPLv3、第三方库许可证、账号隐私、平台使用范围和版权责任。
