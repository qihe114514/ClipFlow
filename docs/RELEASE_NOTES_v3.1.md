# ClipFlow v3.1 更新说明

ClipFlow v3.1 重点优化了页面导航和底部操作栏的交互连贯性，同时移除了动态视频壁纸支持，保留静态壁纸和原有的解析、下载功能。

## 这次更新了什么

### 导航和界面

- 新增 Miuix 液态风格底部导航栏，支持拖拽、按压反馈和回弹动画。
- 新增可保存状态的横向分页，底部导航与页面滑动保持同步。
- 页面滑动时实时更新底部导航指示器，减少切页过程中的状态跳变。
- 稳定分页、路由和底部导航之间的动画交接，提升快速滑动和返回操作的连续性。

### 壁纸和维护

- 移除动态视频壁纸支持，保留静态壁纸功能。
- 补充导航交互测试和项目文档，更新 README 截图与演示内容。

## 升级说明

- 不需要清除旧数据。
- 原有的解析历史、下载位置、应用设置和隐私同意状态会保留。
- 本版本最低支持 Android 12（API 31）。
- 版本名称为 `3.1`，内部版本号为 `42`。

## 安装方式

1. 下载本版本 Release 中的 `ClipFlow-v3.1.apk`。
2. 点击 APK 开始安装。
3. 如果 Android 提示允许当前来源安装应用，请按提示打开权限。
4. 安装完成后，可以关闭“允许安装未知应用”权限。
