# ClipFlow v3.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a dedicated open-source notice page under About, update ClipFlow to v3.2 (47), and publish a verified GitHub Release APK.

**Architecture:** Add one secondary Navigation Compose destination and a small stateless Compose page that reuses existing `GlassCard` and detail-page navigation. Keep existing Bilibili, bottom-bar, download, and privacy behavior unchanged.

**Tech Stack:** Kotlin 2.3.10, Jetpack Compose, Material 3, Navigation Compose, Gradle 9.6/JDK 21, GitHub Releases.

## Global Constraints

- Preserve existing uncommitted user changes; do not include `.rej` files.
- Keep GPLv3 and third-party license disclosures explicit.
- Do not put cookies, account data, or secrets in docs or release notes.
