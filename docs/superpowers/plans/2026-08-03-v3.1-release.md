# ClipFlow v3.1 Release Plan

**Goal:** Publish the changes after the v3.0 tag as a v3.1 GitHub release with a verified release APK.

**Scope:** Include every commit from `v3.0..HEAD`, set `versionName` to `3.1`, set `versionCode` to `42`, and preserve the existing signing/build conventions.

**Files:**
- Modify: `app/build.gradle.kts` for release version metadata.
- Modify: `increment_version.ps1` so future packaging increments only `versionCode`.
- Modify: `CHANGELOG.md` with the v3.1 entry.
- Create: `docs/RELEASE_NOTES_v3.1.md` for the GitHub release body.
- Leave untouched: existing user changes under `docs/research/`.

**Verification:**
- Review the complete `v3.0..HEAD` commit list and diff summary.
- Run offline unit tests and the release assemble task with the cached Gradle runtime.
- Inspect the generated APK with Android build tools and verify version name/code and release artifact existence.
- Run `git diff --check`, inspect the final diff, push `main` and tag `v3.1`, then read the GitHub release and asset metadata back after publication.

**Release artifact:** Rename the verified output to `ClipFlow-v3.1.apk` and upload it to the `v3.1` GitHub release.
